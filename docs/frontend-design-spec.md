# 企业知识问答系统 · 前端视觉设计方案

> 风格方向：**国风水墨 · 极简 · 反俗（Anti-Slop）**
> 版本：v1.0（定稿） · 日期：2026-08-27
> 配套视觉稿：登录页 / 问答主界面 / 知识库管理页（链接见文末）

---

## 一、设计定位

### 1.1 一句话定位

把「企业知识问答」从 Element Plus 默认的蓝紫后台风，改造成**水墨留白的文人编辑气质**：墨分五色、少即是多、靠留白与字重撑层次，杜绝 AI 生成界的常见俗套。

### 1.2 Design Read（设计读取）

基于 taste-skill（Anti-Slop Frontend）框架的声明：

> 读取为：企业内部知识问答**产品应用**，面向企业员工，采用**水墨 heritage 语言**，倾向「纯单色 + 单一强调、编辑感、克制留白」的美学族。

### 1.3 三表盘（Dials）

| 表盘 | 值 | 含义 |
|---|---|---|
| DESIGN_VARIANCE | 5 | 非对称留白，有呼吸感但不乱 |
| MOTION_INTENSITY | 3 | 几乎静止，仅 hover/active 反馈 |
| VISUAL_DENSITY | 2 | 画廊式留白，元素极少 |

## 二、设计原则（反俗纪律）

设计全程应用 taste-skill 提取的反 AI 俗气纪律：

1. **禁纯黑/纯白**：墨色用带暖调的深灰（off-black），背景用带暖调的浅灰白（off-white）。纯黑纯白显"死"。
2. **排版层级靠字重/字号，不靠卡片框**：回答正文直接文字流，不用气泡/卡片包裹。
3. **非对称留白**：内容不居中堆砌，用偏置 + 大留白制造呼吸感。
4. **零装饰**：不用装饰性圆点、分隔线、标签框、emoji；引用出处是一行小字而非标签。
5. **单一强调色**：全站最多一个强调色（本方案为水墨单色，几乎零彩色）。
6. **禁止 em-dash**：文案中不使用「——」，一律用句号/逗号/冒号。
7. **文案真实**：回答正文、状态文案必须真实可读，杜绝 AI 幻觉式乱码与假精确数据。
8. **形状一致性**：全站统一圆角体系（默认 4-6px 细圆角）。
9. **按钮对比度**：主按钮墨底白字，满足 WCAG AA。
10. **避免等宽卡片网格**：三张等宽卡片的"AI 默认布局"被禁止，改用列表 + 详情等非对称结构。

## 三、视觉规范

### 3.1 配色系统（核心）

水墨关键：墨分五色 + 少即是多。

| 角色 | 色值 | 说明 |
|---|---|---|
| 纸底（bg） | `#F7F5F1` | 全局背景，带暖调的浅灰白（off-white） |
| 卡片/气泡面 | `#FDFCFA` | 极少使用，仅在需要强调时 |
| 墨色主文字 | `#2B2A28` | 标题、品牌、用户问题、主操作（off-black） |
| 次墨文字 | `#6E6A63` | 正文 / AI 回答 |
| 淡墨文字 | `#A6A199` | 占位符、时间、出处、次要信息 |
| 细线 | `#E3DED2` | 极细分割线、输入下划线 |
| 强调（可选用） | `#A63A2E` 朱砂 | 仅限印章 logo / 极少量跳色，全站唯一强调 |

> 说明：水墨方向为"纯单色"，默认不使用朱砂；如需一点生气，仅在印章 logo 处保留朱砂，全站其余保持黑白灰。

### 3.2 字体系统

| 用途 | 字体 | 说明 |
|---|---|---|
| 标题 / 品牌 | 思源宋体（Noto Serif SC） | 宋体自带书卷气，符合水墨 heritage 气质 |
| 正文 | 思源黑体 / 苹方（PingFang SC） | 保证可读性 |
| 数字/代码 | JetBrains Mono（可选） | 回答中代码块 |

- 字距略宽、行距 1.7+，疏朗不拥挤。
- 层级完全靠字重与字号：品牌墨黑粗、正文次墨常规、次要淡墨小号。

### 3.3 圆角 / 阴影 / 线条

- 圆角：统一 6px（按钮/输入），全局一把尺子，不混用。
- 阴影：尽量不用；必须用时用带纸色倾向的极淡投影，禁止纯黑投影。
- 线条：只允许极细（1px）浅色线，用于导航分隔、输入下划线、列表行间。

### 3.4 图标

- 禁用 emoji（📚💬📁🧋 全部移除）。
- 使用 Element Plus 图标或统一线性图标，墨色 `#2B2A28`，一套 family，统一直线宽度。
- Logo：墨黑方形印章 + 白色反白「问」字（可用内联 SVG 实现）。

## 四、布局与组件规范

### 4.1 全局布局

- 顶部极简导航栏（高 56px）：左「印章 + 品牌名」→ 中「智能问答 / 知识库管理」→ 右「头像」。当前项墨黑加粗 + 一条极细墨黑下划线，不用高亮块。
- 主内容区大留白，页面最大宽度约 1200px，四周 padding 充足。
- 全站单一主题（浅色水墨），不做中途换肤。

### 4.2 组件

| 组件 | 规范 |
|---|---|
| 主按钮 | 墨黑底、白字、6px 圆角；CTA 文案 ≤3 词，单行不换行 |
| 文字按钮 | 墨灰文字，hover 变墨黑 |
| 输入框 | 无边框无底色，仅底部一条极细墨灰线；标签在输入框上方（禁止占位符当标签） |
| 列表 | 行间极细浅灰线分隔，不用卡片框；状态用纯文字（墨黑/次墨/淡墨三档），不用标签 |
| 对话气泡 | 不包裹气泡；用户问题墨黑靠右，AI 回答次墨靠左，靠对齐与留白区分 |
| 引用出处 | 回答下方一行淡墨小字「来源：文件名 第N页」，无标签框 |
| 弹窗 | 无重投影，细描边，标题墨黑 |

## 五、页面设计明细

### 5.1 登录页

- **构图**：非对称留白。内容偏置左下方，右上仅一笔极浅淡墨远山剪影，右下大留白。
- **元素**：墨黑「问」字印章 → 宋体标题「企业知识问答」→ 淡墨副标题「基于企业知识库的智能问答系统」→ 两个下划线输入框（用户名/密码）→ 墨黑通栏按钮「登 录」→ 一行淡墨版权小字。
- **要点**：无卡片框、无投影、内容不居中，留白即设计。
- **视觉稿**：`https://aka.doubaocdn.com/s/4UQwv81Ki0`

### 5.2 问答主界面

- **构图**：顶部导航 + 左会话栏 + 右对话区 + 底部输入线。
- **元素**：
  - 导航：品牌 + 印章 + 「智能问答 / 知识库管理」+ 头像（写死三项，勿重复）。
  - 左会话栏：无按钮框，浅灰小字列会话标题，当前墨黑加粗 + 左侧墨黑细竖线。
  - 对话区：用户问题墨黑靠右，AI 回答次墨正文靠左、行距疏朗，出处一行淡墨小字。
  - 底部：一条极细墨灰线 + 淡墨占位「输入你的问题，Enter 发送」+ 墨黑小圆发送点。
- **要点**：回答正文直接文字流，无卡片；留白充足。
- **视觉稿**：`https://aka.doubaocdn.com/s/1jbYtALVoP`

### 5.3 知识库管理页

- **构图**：非对称左右布局。左栏知识库列表 + 右栏选中库详情。
- **元素**：
  - 左栏：「知识库 / 技术文档库」分组标题 → 库名列表（当前墨黑加粗 + 左侧墨黑竖线）→ 底部「＋ 新建知识库」墨黑小按钮；左下角可衬一幅淡墨山水装饰。
  - 右栏：墨黑标题「产品知识库」+ 淡墨「私有 · 12 篇文档」→ 淡墨描述 → 「文档」小标题 → 极细线分隔的文档行（文件名 + 状态文字 + 切片数）。
- **要点**：避开三张等宽卡片；状态用纯文字（已完成/已上传/向量化中/失败）。
- **视觉稿**：`https://aka.doubaocdn.com/s/UDt3pfvwIf`

## 六、落地实现指南（Vue3 + Element Plus）

### 6.1 第一步：替换全局变量（`frontend/src/styles/main.css`）

```css
:root {
  /* 水墨色板 */
  --bg: #f7f5f1;            /* 纸底（off-white） */
  --card: #fdfcfa;
  --ink: #2b2a28;           /* 墨黑主文字（off-black） */
  --ink-2: #6e6a63;         /* 次墨正文 */
  --ink-3: #a6a199;         /* 淡墨次要 */
  --line: #e3ded2;          /* 细线 */
  --seal: #a63a2e;          /* 朱砂（可选强调） */

  /* Element Plus 主题覆盖 */
  --el-color-primary: #2b2a28;
  --el-color-primary-light-3: #4f4c47;
  --el-color-primary-light-5: #8b877f;
  --el-color-primary-light-7: #c9c5bd;
  --el-color-primary-light-8: #e9e6e0;
  --el-color-primary-light-9: #f4f2ee;
  --el-border-radius-base: 6px;
  --el-text-color-primary: #2b2a28;
  --el-text-color-regular: #6e6a63;
  --el-text-color-secondary: #a6a199;
  --el-border-color: #e3ded2;
}
```

### 6.2 第二步：按文件调整

| 文件 | 调整点 |
|---|---|
| `src/styles/main.css` | 替换上表变量；`.md-body` 代码块去灰底改极浅纸色；blockquote 改淡墨左边线 |
| `src/views/Layout.vue` | 导航去高亮块，当前项墨黑下划线；emoji logo 换「问」字印章；菜单文字墨灰 |
| `src/views/Login.vue` | 去卡片与投影、去蓝色渐变；内容偏置 + 右侧淡墨装饰；按钮墨黑 |
| `src/views/Chat.vue` | 会话栏去按钮框、行距加大；当前项墨黑加粗 + 左竖线；输入框改下划线式 |
| `src/components/ChatMessage.vue` | 去气泡背景与边框，用户墨黑靠右 / AI 次墨靠左；引用改一行小字；头像改墨黑圆 |
| `src/views/Knowledge.vue` | 知识库列表去三列卡片，改左列表 + 右详情；文档表格改细线行列表，状态纯文字 |
| 全局 | 移除所有 emoji 图标，替换为 Element 线性图标（墨色） |

### 6.3 第三步：品牌元素

- 印章 logo：内联 SVG（墨黑方 + 白「问」），登录页与导航复用。

### 6.4 验收清单（taste-skill Pre-Flight 精简版）

- [ ] 全站无 emoji、无装饰圆点、无 em-dash
- [ ] 无纯黑 `#000` / 纯白 `#fff`
- [ ] 单一主题、单一强调色、单一圆角体系
- [ ] 按钮墨底白字，对比度 ≥ 4.5:1
- [ ] 回答正文真实可读，无幻觉文案
- [ ] 导航单行、三项不重复
- [ ] 无三张等宽卡片、无居中堆砌
